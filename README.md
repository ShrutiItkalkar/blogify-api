# Blogify API

A professional blogging platform backend API built with Node.js.

## Project Structure

```
/blogify-api
├── .git/
├── .gitignore
├── README.md
├── package.json
├── package-lock.json
└── src/
    ├── controllers/
    ├── routes/
    ├── services/
    ├── utils/
    └── index.js
```

## Getting Started

### Installation
```bash
npm install
```

### Development
Run with auto-reload using nodemon:
```bash
npm run dev
```

### Production
Run with Node:
```bash
npm start
```

The server will start on http://localhost:3000
